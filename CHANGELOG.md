# Changelog

## 1.1.0
- `setSeparator(';', true)`: разделитель столбцов и десятичная запятая для Excel с русскими и казахскими региональными настройками. Заголовок, время и ячейки с разделителем внутри берутся в кавычки сами.
- ESP32: `begin(cs, spi, name, hz)` для модуля SD на своих пинах SPI (шина HSPI), повторная попытка после вынутой карты идёт по той же шине.
- Примеры ExcelRu и ESP32_CustomSPI. Тесты: четыре варианта разделителей, кавычки, ротация с разделителем, своя шина; мутации ловятся.
- Предыдущее: Первый выпуск: запись CSV на SD, заголовок, столбец времени, своё время (RTC).
- Ротация файлов по размеру, продолжение в последнем файле после перезапуска.
- Сброс на карту по таймеру, восстановление после извлечения карты.
- Понятные ошибки и `diagnose()` на русском, казахском и английском.
